# MergeReviewer 0.19.0

發布日期：2026-10-23。由正式版 0.17.0 升級，包含 0.18.0 與 0.19.0 候選版的累積更新。

## 本版更新

- 以 start／step／check／finish／status／cancel 管理可恢復的審查請求，保留操作 checkpoint、固定來源與既有 v3／退出碼相容性。
- 協調並行同步，重用有界的同步結果、固定 peer packs 與同一 context 的搜尋結果；finish 重新驗證固定證據。
- 新增可選的 boundary-contracts/v1，分開追查 Repo 內使用路徑與跨 Repo 契約，保留必要消費端、影響連通性及未完整判斷。
- 提供零 Git 草稿診斷；發布收據支援中斷恢復、清理重試與人工確認區編輯，已發布狀態保留原審查缺口。

## 已接受的驗收限制

本次依使用者於 2026-10-23 明確接受限制的決定發布正式版。原候選版的正式模型品質／效能驗收仍為未通過，沒有將原紀錄改為成功。完整自動化 CI 仍是獨立且必要的發布條件。

- 原目標要求大型案例 6/6 有效配對，端到端 candidate/base 耗時比中位數不超過 0.70；MergeReviewer 最終僅 4/6 有效，中位數為 0.9840，未達 30% 改善目標。
- 兩個 Reviewer 合計 48 次最終 agent 執行取得 47 份報告；另一次無報告失敗仍保留，不能宣稱 48 次完整審查均成功。
- 靜態品質及情境 oracle 的未達項與失敗紀錄維持原判定。helper／Git／搜尋計數不代表模型時間，也不能推論完整流程已加速 30%。
- 既有 VS Code CLI 隔離安裝與 installed-resources 流程驗證已執行；Native UI 與 production activation 未驗證。

本版維持技能公開介面相容。發布證據另外保存原始 acceptance-record、驗收摘要、必要報告與追蹤紀錄，以及本次正式 CI、來源提交及附件 SHA-256。
