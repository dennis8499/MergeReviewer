# MergeReviewer 0.20.1

發布日期：2026-10-28。依使用者確認先行發布，保留以下尚未完成的驗收限制。`v0.20.0` 因 Windows／Python 3.10 計時測試失敗而未發布；本版以受控時鐘修正該測試，並保留原標籤及失敗紀錄。

## 本版更新

- 遠端同步改為逐 ref 重用，同一工作區的不同 head 可共用有效 base；各審查仍固定自己的 SHA、證據與報告。
- 合併重複的工作區探索、固定物件讀取與搜尋，finish 仍以獨立快取重新核對固定證據。
- 新的 `boundary-contracts/v2` 依實際影響記錄 contained、propagates 或 unresolved；舊 v3 草稿及進行中的舊 context 保持相容。
- 新增 `merge-reviewer-authoring/v1` 精簡草稿及分段回應，區分已保存、已傳回與語意已審查。

## 已驗證與尚未完成

- Windows Python 3.14 完整回歸執行 330 項，328 項通過、2 項因 symbolic link 權限不足而跳過；BDD 16 個自動情境通過。正式發布由 CI 的 Windows／Linux、Python 3.10／3.14 矩陣驗證。
- 固定合成夾具的五組 helper 機械重播，大型多 Repo 暖快取／冷啟動／陸續啟動中位比值為 0.697／0.765／0.717；單 Repo 為 0.996／1.032／1.020。固定證據及驗證結果一致；此前未達標的 0.792 和 1.071 輪次保留。
- 完整模型審查時間的 15% 改善、三模型品質對照及實際 symbolic link 情境尚未完成。helper 數據不能代替完整模型審查或語意品質驗收。

完整方法、數據與待執行矩陣見 [驗收紀錄](../acceptance-ref-sync.md)。逐次資料另保存[大型重播](evidence/v0.20.0/large-after-path.json)、[大型首次未達標輪次](evidence/v0.20.0/large-warm-first.json)、[單 Repo 重播](evidence/v0.20.0/single-after-path.json)及[單 Repo 首次未達標輪次](evidence/v0.20.0/single-first.json)。
