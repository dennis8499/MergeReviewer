# MergeReviewer 0.20.2

發布日期：2026-10-29。這是 `v0.20.1` 之後的修正版，包含審查流程效能調整、驗收工具更新及發版驗證流程修正。

## 本版更新

- 批次讀取固定 Git 物件，重用同一操作內成功的固定來源搜尋結果；finish 仍獨立重播並驗證證據。
- 搜尋快取鍵納入固定來源、Repo、Git 環境與路徑呈現設定；不快取失敗結果，也不將舊式即時來源納入快取。
- 所選 Repo 已是 ancestor no-op 時，可保留該 Repo 的空 coverage；其他 Repo 的擷取缺口仍讓整體審查維持未完成。
- 發版 CI 使用 Windows Python 3.10／3.14 完整矩陣，正式套件由 Windows Python 3.14 產生並依 CI 收據發布。
- 清除已移除的 Megin receipt 發版參照。

## 驗證與尚未完成

- 本機定向回歸 6 項、發版收據測試 28 項通過。完整本機單元測試未完成；完整 BDD 為 13 個情境通過、2 個因受限 Windows 環境拒絕報告硬連結而未完成。正式發布仍受 Windows Python 3.10／3.14 完整單元與 BDD CI 矩陣閘控。
- 合成夾具上的 helper 效能數據不能代表完整模型審查時間，也不能取代語意品質評估。
- 三模型品質對照、完整模型審查效能及實際 symbolic-link 情境仍待驗收；完整狀態與原始證據見[驗收紀錄](../acceptance-ref-sync.md)。

正式發布只採用同一來源 commit 的完整 CI 證據與 canonical ZIP；CI 未通過時不會發布附件。
