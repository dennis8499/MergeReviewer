# MergeReviewer 0.20.4

發布日期：2026-11-01。本版落實審查 Log 分析後的第一批修正，改善可修請求錯誤、證據續讀、草稿驗證及本機 Git 工作。

## 本版更新

- 在讀取證據前預檢操作欄位、Repo、來源、路徑、操作 ID 與已知行數；把確認過的行數綁定固定來源及 blob SHA，修正越界請求時不再重掃整份 pack。
- 新增 context/runtime 範圍的唯讀 artifact 續讀，回傳完整續讀參數；分頁不新增 step 操作，也不執行 Git。
- 讓 check 提前檢查 parent 與最終來源引用；允許契約錨定本次比較左側實際刪除的符號。
- 支援 compact 草稿、CP950／UTF-16 解碼、二進位檔 metadata，並在展示層遮罩敏感值。
- 合併 merge history 查詢，只擷取必要且與變更路徑相交的 parent view；補上階段進度、read/search/page/retry/lock/finish 計量。
- 保留既有 Git Server 同步去重與 300 秒有效期。本次資料中的 fetch 等待占比低，未提高網路並行度或延長 TTL。

## 驗證與尚未完成

- 本機定向回歸、編碼／預檢／續讀測試通過；完整單元與 BDD 矩陣由本版 GitHub Actions 發行工作流程驗證。
- 大型審查效能比值、暖快取與冷啟動門檻仍待固定快照配對測量；目前不宣稱達到目標加速比例。
- Git 傳輸層 HTTP／SSH 請求數、完整模型審查時間與 token 未觀測；不得從 fetch 次數或剩餘 helper 時間推算。
