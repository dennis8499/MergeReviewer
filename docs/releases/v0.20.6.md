# MergeReviewer 0.20.6

發布日期：2026-11-04。本版修正工作區掃描、存續檔案的刪除契約錨點及契約圖提前檢查，並提供固定證據驗證進度。

## 本版更新

- Repo 掃描略過工具管理的 runtime 子目錄，保留明確宣告的根及 kit 其他子目錄中的 Repo；真正受審範圍的讀取錯誤仍明確失敗。
- 刪除 API／欄位但保留檔案時，可用實際比較左側的移除行註冊舊符號契約。分支分歧使用 diff_base，merge-preview 使用 head；錯誤 SHA、錯誤來源與未修改行會被拒絕，最終內容覆蓋要求保留。
- check 與 finish 共用契約自身位置及 coverage 影響圖起點規則，提前拒絕掛在錯誤 Repo、版本或路徑的節點；check 維持零 Git。
- capabilities 新增 validation_progress；status 與摘要提供 Repo、契約、搜尋完成數、預讀活動及最後更新時間，涵蓋完整性重驗與正式驗證。預讀不算驗證完成，發布後重試保留最後計數。
- 品質矩陣新增刪除仍被使用的 API 與安全刪除反例，保留三模型、三種技能條件及獨立語意稽核方法。既有 v3、compact 及 CLI 介面保留。

## 驗證與範圍

- 升版前的 Windows／Python 3.14.7 完整單元測試：390 通過、3 跳過；兩項缺少 symbolic-link 權限，一項僅適用 POSIX 檔案模式。
- 自動 BDD：15 個情境、62 個步驟通過；28 項本機發布合約及 ZIP 獨立執行通過。Python 3.10 語法解析不代替該版本的執行驗證。
- 對固定 0.20.5 基準完成五組交錯 helper 重播，證據、finding 及缺口一致；兩版每組均為 7 次工具往返、71 次 Git、1 次 finish 及 1 次完整驗證。配對耗時比中位數為 1.02108，約增加 2.1%，不宣稱加速；原始波動及較慢配對保留於[驗收紀錄](../log-workflow-optimization.md#2026-11-04-後續改善)。
- 發版只另更新版本及安裝指南，helper 摘要保持相同。正式 Release 由同一最終 commit 的 Windows／Python 3.10、3.14 CI 驗證，直接發布驗證過的 ZIP；Actions 證據及附件摘要由發布流程附於 Release。
- 三模型實際審查、完整模型時間與企業 runtime 身分／ACL 仍待獨立驗收。Helper 測試與合成來源 oracle 不代表模型品質通過；本版不改動企業帳號或外部 runtime 權限。
