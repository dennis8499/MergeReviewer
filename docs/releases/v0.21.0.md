# MergeReviewer 0.21.0

日期：2026-11-11。此文件記錄 0.21.0 的功能及驗收範圍。

## 改善

- check 與 finish 共用完成度分類，發布前呈現必要缺口與待確認；新增選填 `scope_notes`，未執行測試保留於 `tests_not_executed`。
- reviewed coverage 的缺值／null reason 相容為空文字，其他錯誤型別提前回草稿診斷。純 formatter 故障保留固定證據供診斷，terminal 停止並於 24 小時後由下次 start 惰性清理；cancel 可提前清理。
- 修正 operation-complete 被 prefetch 完成分支攔截的錯誤。成功、部分失敗及重用操作均保存真實完成數，操作耗時於各自完成時結算。
- 新增唯讀 `preflight`，fresh start 的輸入錯誤不消耗 request ID。既存 request 保留固定快照與輸入身份。
- `status --summary` 與 `view --read-only` 不寫 metrics、lock 或 artifacts；check 保存有時間戳的語意待辦摘要供工作台檢視。
- Skill 優先沿 remaining 補查可取得的證據；確實受阻才發布未完成報告，能力確認後採 compact，保留 v3 相容。

## 驗收與界線

`tests/test_session_contracts.py` 以脫敏案例驗證 null reason、完成度、非阻擋說明、唯讀零寫入、啟動參數漂移、操作重用／計時及渲染故障保留／清理。既有發布收據、輸出重試與固定來源驗證不放寬。

這些測試驗證 helper 行為，不代表真實模型審查品質或企業環境效能已達標。三專案安裝整合、配對效能與模型驗收由整合工作紀錄另行保存；本版不宣稱未量測的加速。
