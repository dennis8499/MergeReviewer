# MergeReviewer 0.21.1

日期：2026-11-11。此版修正多 Repo 審查把 Repo 內行為契約擴大成全工作區搜尋的問題。

## 變更

- boundary v2 新契約必須明確選擇 `repo-local`、`identified-repos` 或 `workspace`。
- `identified-repos` 以 `candidate_repos` 列出固定證據指出的消費端 Repo，只對這些 Repo 搜尋每個契約詞。
- `workspace` 仍完整搜尋所有候選 Repo；必要消費端已知但來源缺失時，保留 `unresolved`。
- `CONTRACT.md` 檔名、public 函式或泛稱 export 單獨不再構成跨 Repo 證據。
- 舊 context 省略 `search_scope` 時維持原本保守的 workspace 行為。

## 驗證

`tests/test_boundary_policy.py` 涵蓋明確範圍、只搜尋指定消費端、拒絕未指定 Repo 搜尋，以及必要消費端缺失時保持未完成。

本版模型配對評測結果尚待完整七案例、三組配對及獨立評分完成；此文件不宣稱模型驗收通過。
