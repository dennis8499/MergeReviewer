# MergeReviewer 0.22.0

- 批次預抓與正式搜尋共用 Repo 範圍解析，repo-local／identified-repos 不再預掃無關 peer。新契約依操作順序成立後才搜尋，非法範圍不執行 Git。
- `atomic_authoring` 能力新增 `step` 的 `author` 操作：比較草稿 hash、合併 compact 更新列、保存續作 checkpoint；同操作 ID 可重送，衝突不覆寫。模型負責所有語意判斷。
- `status --summary` 讀保存的進度及最近檢查，不載入、展開或重新驗證整份草稿。`check_current`／`checkpoint_current` 標示是否仍對應目前內容。
- 相同 blob 共用回應正文，保留每個來源及原始操作收據。報告結論與計數由最後驗證產生，首次發布仍完整重驗來源與搜尋。

使用方式見 [草稿格式](../../skills/merge-reviewer/references/authoring.md)。真實模型速度仍須以同來源、模型與強度配對驗收。
