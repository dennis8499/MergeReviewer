# MergeReviewer 0.23.0

新增 `paging_state` 與 `operation_schema` 能力。`view --requests-file` 同時支援舊陣列與明確確認的 `MergeReviewPaging/v1`；新格式沿原生 continuation 續讀、去重並保留待修復項，整體 UTF-8 輸出包含控制資訊仍受 24 KiB 限制。唯讀 view 不寫檔、不執行 Git。

原子 author 保存完整分頁 artifact，獨立 checkpoint revision 防止草稿未變時的進度回退。summary 只提供計數及完整引用；恢復時沿唯讀引用讀完整狀態。頁面已返回不代表完成語意覆蓋。

新增無 runtime 的 `schema --operation` 與子命令幫助。完整來源、契約錨點、必要證據與首次發布驗證維持原契約；活動 request 保留原安裝，不混換 helper。

修正 runtime 所有權標記建立中的啟動預檢競態，保留嚴格所有權驗證；驗證進度新增各活動累積秒數。Output Style 僅在使用者明確要求或選取時載入，預設沿用原報告風格與證據契約。

本輪驗證紀錄包含分頁／原子保存／恢復的實際 worker、固定來源與 finding/outcome oracle、五組交錯 helper 配對，以及 18 次選定情境的模型品質觀測與獨立 Agent 稽核。helper 計時不代表模型審查速度，模型品質 fixtures 亦未實際採用新分頁 view；整體模型審查加速仍未證實。

量測、具名測試對照、歷史候選產物 hash、原始證據位置及未覆蓋範圍見[本機驗證紀錄](../validation/review-efficiency-20261115.md)。正式附件與來源身份由本版 GitHub Release 的完整 CI 矩陣及 Verification 收據核對；歷史候選 hash 不代替正式附件收據。
